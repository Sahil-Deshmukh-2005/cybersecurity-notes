# Module-8 : Web Hacking

## Room-1 : Web Application Basics

Web Application can be divided into two parts   
1. Frontend  
2. Backend

### Frontend
`Frontend` is the surface of the web application.  

1. HTML :  
`HTML` is like a skeleton of web. A basic structure of any designed website.

2. CSS :  
`CSS` is like skin, color, muscles, etc.. of web.

3. JS :  
`JS` is the functioning of the body walking, eating, etc... for the web application.


### Backend
`Backend` is what we dont see on the surface but without it running a website is likely impossible.  

1. Database :
It is where the data is stored, retrieved, modified of an user.

2. Other Infrastructure Component :
Components like web servers, application servers, storages, etc...
