# Module-8 : Web Hacking

## Room-1 : Web Application Basics

***

Web Application can be divided into two parts   
1. Frontend  
2. Backend

#### Frontend
`Frontend` is the surface of the web application.  

1. HTML :  
`HTML` is like a skeleton of web. A basic structure of any designed website.

2. CSS :  
`CSS` is like skin, color, muscles, etc.. of web.

3. JS :  
`JS` is the functioning of the body walking, eating, etc... for the web application.


#### Backend
`Backend` is what we dont see on the surface but without it running a website is likely impossible.  

1. Database :  
It is where the data is stored, retrieved, modified of an user.  

2. Other Infrastructure Component :  
Components like web servers, application servers, storages, etc...  

3. Web Application Firewall :  
This is a protective shield over the web application which filters out the dangerous requests.

***

### URLs 
We have already seen important things about `URLs`,  
The process of coping a popular website's URL any registaring a some what similar URL website for phishing, is called `typosquatting`.

***

### HTTP Messages (Request/Response)
1. Start Line :  
This gives introduction about the message.

2. Header :  
Header is a set of Key:Value pairs, that gives extra information about the message.

3. Empty Line :  
After Header there is always a empty line.

4. Body :  
Body is where the actual data is stored.
